# Security Awareness Training Guide

All employees complete a security awareness module during onboarding and a
refresher annually. The training covers recognizing phishing attempts,
safe password practices, and how to report a suspected security issue.

Phishing emails often create urgency, ask for credentials or payment
details, or come from an address that looks similar to a real contact but
is subtly different. Employees should hover over links before clicking and
report suspicious emails using the "Report Phishing" button rather than
forwarding them to colleagues.

NexaCore Solutions also runs periodic simulated phishing tests. Employees
who click a simulated phishing link are shown a short educational message
and are not penalized; the goal is awareness, not enforcement. Repeated
clicks may prompt a manager conversation focused on additional support
rather than discipline.

Any suspected real security issue, including a suspicious email, an
unexpected password reset request, or a lost device, should be reported to
IT Security immediately rather than investigated independently by the
employee.
