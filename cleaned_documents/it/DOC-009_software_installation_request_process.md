# Software Installation Request Process

Employees who need software not available in the standard IT catalog can
submit a request through the IT ticketing system. Requests should include
the software name, business justification, and whether the tool will
handle any company or customer data.

Requests are reviewed within three business days. Tools that handle
sensitive data require an additional security review, which can take up to
two weeks depending on the vendor's responsiveness to security
questionnaires. Free trials of unapproved software should not be installed
without submitting a request first, even for evaluation purposes.

Once approved, IT installs the software remotely for managed devices or
provides installation instructions for cases where remote installation is
not possible. Approved software is added to the internal catalog so future
requests for the same tool by other employees can be fast-tracked.
