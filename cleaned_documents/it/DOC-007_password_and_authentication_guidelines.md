# Password and Authentication Guidelines

All NexaCore Solutions accounts require multi-factor authentication in
addition to a password. Passwords must be at least twelve characters and
should not reuse a password from a personal account or a previous company
password.

The company password manager is the recommended way to generate and store
credentials for internal tools. Passwords should never be written down on
paper, stored in an unencrypted document, or shared over chat or email,
even with a manager or IT support.

If an account is suspected of being compromised, employees should change
the password immediately and report the incident to IT Security through
the helpdesk, marking the ticket as urgent. IT Security may temporarily
lock an account while an investigation is in progress.

Authentication tokens for automated systems and integrations should be
rotated every ninety days and stored in the approved secrets management
tool rather than in code or configuration files.
